I contribute to Robot Indoor through the MA64 Robotics Association, focusing on ROS2 navigation behavior for indoor mobile robot systems.

Robot Indoor is an academic and community platform for learning and experimenting with indoor mobile robotics. It combines Gazebo simulation, ROS2, SLAM Toolbox, Nav2, RViz visualization, frontier exploration, and reproducible development environments.

My work includes implementing a Regulated Pure Pursuit controller for trajectory execution in the follow-me navigation feature, while contributing to the navigation logic used inside the simulated indoor workflow.
