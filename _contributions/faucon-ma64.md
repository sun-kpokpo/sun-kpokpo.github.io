I contribute to Faucon MA64 through the MA64 Robotics Association, focusing on autonomous navigation tooling for agricultural mobile robot systems.

Faucon MA64 is an open-source autonomous agriculture robotics project built around a ground robot and drone concept. The broader stack includes ROS2 Jazzy, Gazebo simulation, Nav2, PX4 SITL, BehaviorTree.CPP orchestration, localization, perception, path planning, and a web-based supervision interface.

My work includes a ROS2 node for GPS waypoint collection and logging, plus boustrophedon coverage path planning with Dubins curve U-turns for field coverage.
